# 로컬 브라우저 검증(e2e)

실제 Supabase 없이 앱 전체를 띄워 주요 흐름을 브라우저로 확인한다.

| 구성 | 역할 |
| --- | --- |
| 로컬 Postgres | `supabase/tests/supabase_stub.sql`(Supabase 기본 구성 흉내) + 마이그레이션 + `seed.sql` |
| PostgREST 12 | Supabase REST API와 같은 서버(처음 실행 때 `.bin/`에 내려받음) |
| `fake-supabase.mjs` | 로그인, 관리자 API(공용 계정 만들기), REST 전달, 파일 저장 흉내. 실시간 기능은 없어 표시등은 "자동 확인"으로 나온다 |
| `mock-push.mjs` | 브라우저 푸시 서버 흉내(자체 서명 인증서) |
| Playwright | Pixel 7, iPad Pro 11, 노트북 화면으로 시나리오 실행 |

## 실행

```bash
PG_TEST_URL=postgres://postgres:postgres@localhost:5432/postgres bash e2e/run.sh
```

필요한 것: Postgres 16 이상과 `psql`, Node.js, Python 3 + `reportlab`, `openssl`, `curl`, Playwright(프로젝트에 없으면 전역 설치본이나 `PLAYWRIGHT_MODULE` 경로를 쓴다).
실행하면 테스트용 환경 변수로 `npm run build`를 다시 하므로 끝난 뒤 배포용 빌드가 필요하면 다시 빌드한다.

## 시나리오

실행 순서대로 적었다. 처음 설치 시나리오는 앱 표가 없는 빈 데이터베이스에서 시작하고, 나머지는 예시 데이터를 다시 넣은 뒤 실행한다.

| 파일 | 확인 내용 |
| --- | --- |
| `setup.mjs` | 표가 없을 때 "사이트 준비하기" 화면, 버튼 한 번으로 표와 권한 정책, 처음 비밀번호, 알림 키 생성 |
| `api-check.mjs` | 화면에서 쓰는 조회 문장의 결과 모양과 권한(로그인 없는 읽기, 초안 숨김, 쓰기 거부, 서버 전용 표 차단, 버전 번호, 필기 권한 등) |
| `visitor.mjs` | 로그인 없이 홈, 처음 방문 안내와 이름, 실시간 표시등, 악보 보기, 이 기기 개인 필기(펜, 글자, 되돌리기, 지우개, 새로고침 후 유지), 확대, 다음 곡, 초성 검색, 지난 예배, 틀린 비밀번호, 접속 기록 |
| `leader.mjs` | 비밀번호 1234로 리더 모드, 순서 변경, Key, 기존 곡 추가, 새 곡과 PDF 등록, 최신 파일로 교체, 변경 알림, 새 예배 공개, 공용 필기와 방문자 화면 표시, 모드에서 나가기 |
| `admin.mjs` | 비밀번호 1221로 총 관리자 모드, 접속 기록과 상세(본 화면과 머문 시간), 많이 본 악보, 관리 기록, 비밀번호 바꾸기, 곡 이름 바꾸기와 삭제 거부, 기기별 미리보기, 연속 실패 잠금 |
| `pinch.mjs` | 두 손가락 확대, 태블릿 화면, 노트북 화면의 위쪽 메뉴 |
| `push.mjs` | 공개 알림 발송(VAPID, 암호화), 보낸 기기 제외, 만료 구독 정리, 연속 알림 방지, 서비스 워커 알림 표시 |

관리 모드 비밀번호는 처음 값(`1234` 리더, `1221` 총 관리자)을 쓴다. `admin.mjs`는 중간에 리더 비밀번호를 `5678`로 바꾼다.
화면 캡처는 `e2e/.work/shots`에 남는다.
